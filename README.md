# Merge Workforce Desktop Client — Downloads

This repository is the public distribution point for the **Merge Workforce desktop
client**, the governed AI client that Merge provisions onto managed devices.

**Downloads are on the [Releases](../../releases) page.**

| Platform | Package |
|----------|---------|
| macOS 13+ | `Merge-Workforce-<version>.dmg` |
| Windows 10/11 | `Merge-Workforce-<version>.msi` |

> **Preview builds.** Releases marked *pre-release* are unsigned preview builds
> intended for evaluation and platform-approval review, not general deployment.
> Production releases will be code-signed and notarized.

The client source is maintained privately by Merge. For access or questions,
contact your Merge representative.
